# Support — StealthBridge Frontend

> **Stellar Testnet engineering only.** StealthBridge is not an active money transmitter and cannot process real transfers, issue quotes, or settle fiat payouts.

## Where to get help

- **UI workflows, Freighter session issues, accessibility, or Next.js BFF routes:** Search [stealthbridge-frontend issues](https://github.com/stealthbridge-labs/stealthbridge-frontend/issues) and check [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) and [docs/PRODUCT-ARCHITECTURE-AND-JOURNEYS.md](docs/PRODUCT-ARCHITECTURE-AND-JOURNEYS.md).
- **API & database issues:** Tracked in [stealthbridge-backend](https://github.com/stealthbridge-labs/stealthbridge-backend/issues).

Include browser/OS, Node version, build mode (`landing` vs `preview`), and scrubbed console/Playwright output. Never paste Freighter secrets, session cookies, passphrases, or personal data.

For security disclosures, follow [SECURITY.md](SECURITY.md) privately.
